# Turbo Rush Racer 🏎️

لعبة سباق سيارات عالية الجودة وفائقة السرعة، مبنية بتقنية pseudo-3D على HTML5 Canvas بدون أي مكتبات خارجية.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادم محلي:
```
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## المميزات
- محرك عرض pseudo-3D بمسار منحنيات وتلال وتصادمات مع سيارات ذكاء اصطناعي
- فيزياز تسارع/فرامل/انزلاق خارج الطريق + نيترو للانفجار السرعي
- صوت محرك ونيترو واصطدام مُصنَّع عبر Web Audio API
- HUD كامل: عداد سرعة، لفات، توقيت، نيترو، ترس، ترتيب
- عد تنازلي قبل الانطلاق، إيقاف مؤقت، أفضل وقت محفوظ محليًا
- تحكم بلوحة المفاتيح أو أزرار لمس على الجوال، تصميم متجاوب بالكامل
