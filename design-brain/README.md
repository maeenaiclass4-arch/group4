# العقل الإبداعي — Design Brain

أداة ويب مستقلة (بدون خادم) تحوّل ملاحظاتك الخام بعد اجتماع العميل إلى اتجاه إبداعي كامل:
تحليل استراتيجي، 5 مفاهيم تصميم مختلفة تمامًا، وبريف إبداعي جاهز للإنتاج — بأسلوب مدير إبداعي أول.

A self-contained (no backend) web tool that turns your rough post-meeting notes
into a complete creative direction: strategic analysis, 5 completely different
design concepts, and a production-ready creative brief — in the voice of a
senior Art Director.

## الاستخدام / Usage

1. افتح `index.html` في المتصفح (أو استضفه كملف ثابت).
   Open `index.html` in a browser (or host it as a static file).
2. اضغط ⚙️ **الإعدادات** وأدخل مفتاح API الخاص بك (Anthropic، OpenAI، أو Google Gemini). المفتاح يُستخدم مباشرة من متصفحك ولا يُرسل لأي خادم آخر.
   Click ⚙️ **Settings** and enter your own API key (Anthropic, OpenAI, or Google Gemini). The key is used directly from your browser and never sent anywhere else.
3. الصق ملاحظات الاجتماع، واضغط **حلّل وابتكر 5 مفاهيم**.
   Paste your meeting notes and click **Analyze & generate 5 concepts**.
4. استعرض التحليل والمفاهيم الخمسة، ثم انسخ أو نزّل البريف الإبداعي النهائي.
   Review the analysis and the 5 concepts, then copy or download the final creative brief.

اللغة الافتراضية للواجهة والمخرجات هي **العربية**، مع زر تبديل إلى **English** في الأعلى.

The interface and generated output default to **Arabic**, with an **English**
toggle in the top bar.
